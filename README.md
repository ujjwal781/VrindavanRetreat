# 🌿 Vrindavan Retreat & Farmstay

A complete farmhouse booking and management system built with modern web technologies, featuring real-time updates, automated email notifications, and a premium user interface.

---

## 🚀 Features

### 🏡 User Side

* Explore premium farmhouse packages
* Real-time booking system
* Date availability check (no double booking)
* Contact form with email integration
* WhatsApp & Instagram integration
* Fully responsive premium UI

### 🔐 Admin Panel

* Secure login authentication
* Dashboard with booking insights
* Calendar view of bookings
* Monthly revenue & stats tracking
* Mark bookings as Paid (instant update)
* Realtime sync across devices

### ⚡ Backend & Automation

* Supabase database integration
* Real-time subscriptions
* Email notifications via Resend
* No page reload updates (modern UX)

---

## 🛠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Supabase (Database + Auth + Realtime)
* **Email Service:** Resend
* **Calendar:** FullCalendar.js
* **Deployment:** Vercel
